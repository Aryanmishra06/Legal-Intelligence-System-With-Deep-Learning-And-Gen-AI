# Legal-Intelligence-System-With-Deep-Learning-And-Gen-AI
AI-Based Legal Intelligence System using Python, Flask, Machine Learning, Deep Learning and Gemini API. It provides court case search, outcome prediction, semantic similarity search, AI-powered case analysis and interactive analytics dashboards.

🚀 Project Overview

The Legal Intelligence System helps users explore court case information, search similar cases, predict case outcomes and analyze judicial data through an interactive dashboard.

It combines traditional machine learning techniques with modern AI technologies to provide meaningful insights from court case datasets.

✨ Key Features

Case Search: Search court cases using case names and related information.

Semantic Search: Find similar cases using TF-IDF and cosine similarity.

Outcome Prediction: Predict possible case outcomes using Machine Learning.

Deep Learning: Use Sentence Transformers and a PyTorch-based classifier.

AI Case Analysis: Generate AI-assisted case analysis using Google Gemini API.

Analytics Dashboard: Visualize case statistics, categories, judges and outcomes.

Category-Based Filtering: Explore cases based on their categories.

Interactive Interface: User-friendly web application.

🧠 Machine Learning & AI

The system uses multiple AI techniques:

TF-IDF and Cosine Similarity for case similarity search.

Random Forest Classifier for outcome prediction.

Sentence Transformers for semantic text embeddings.

PyTorch-based Deep Learning Classifier.

Google Gemini API for AI-assisted case analysis.
